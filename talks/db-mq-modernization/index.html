The Estate Scanner turns evidence into migration decisions

Scan code, MQ configuration, runtime and cost evidence — before proposing routes or effort.
The scanner is the first step — we have no parameters to estimate effort until we've read the estate. It connects static code, config, runtime traffic and cost/inventory into one confidence-rated record per workload, and outputs pattern+confidence, route+migration unit, owner+dependency map. The screenshot is our existing modernization workbench — we reconfigure it to read MQ client & server systems. This is where the Option-2 protocol/semantics question gets answered.
